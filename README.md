# artificial-intelligence-lab-
lab tasks of aritficial intelligence .
Lab 1: This lab compares decision-making rules and tests different student application cases.

Lab 2: This lab explains intelligent agents and uses a smart classroom agent to control temperature.

Lab 3: This lab implements BFS, DFS, DLS, IDDFS and UCS search algorithms.

Lab 4: This lab compares A* and UCS algorithms using a weighted graph and heuristics.

Lab 5: This lab implements Minimax and Alpha-Beta Pruning to compare game-tree searching.

Lab 6: This lab covers text tokenization, FAQ chatbot, text chunking and document searching.
